# 🛒 Análisis Comparativo de Tiendas — Recomendación Comercial para el Sr. Juan

## 📋 Descripción del proyecto

Este proyecto tiene como objetivo analizar el desempeño de **cuatro tiendas** para determinar cuál representa la **mejor oportunidad comercial** para que el **Sr. Juan** venda sus productos.  
El análisis combina métricas financieras, operativas y de satisfacción del cliente, utilizando técnicas de **análisis exploratorio de datos (EDA)** y **visualización estadística**.

Se evaluaron aspectos clave como:
- 💰 **Ingresos totales** generados por cada tienda.  
- 🧾 **Categorías de productos más y menos vendidas**.  
- 🌟 **Calificaciones promedio** otorgadas por los clientes.  
- 📦 **Productos con mayor y menor rotación**.  
- 🚚 **Coste de envío promedio**.  

Con base en estos factores, se genera una recomendación objetiva sobre la tienda ideal para comercializar los productos del Sr. Juan.

---

## 🎯 Objetivos del análisis

- **Identificar** las tiendas con mejor desempeño financiero y operativo.  
- **Evaluar** el comportamiento de las categorías de productos según volumen de ventas.  
- **Analizar** la satisfacción del cliente mediante las calificaciones promedio.  
- **Comparar** los costos logísticos entre tiendas.  
- **Recomendar** la tienda más rentable, eficiente y con mayor potencial de crecimiento.

---

## 🧠 Metodología

1. **Carga y limpieza de datos**  
   - Se importaron los datos de ventas, productos, calificaciones y costos logísticos.  
   - Se corrigieron tipos de datos, valores nulos y formatos de fechas.

2. **Análisis exploratorio de datos (EDA)**  
   - Cálculo de estadísticas descriptivas (media, suma, conteo).  
   - Identificación de las categorías y productos más y menos vendidos.  
   - Cálculo de los ingresos totales y promedios de calificación por tienda.

3. **Visualización de resultados**  
   - Gráficos de barras para ingresos, categorías y productos.  
   - Gráficos de puntos para calificaciones promedio.  
   - Histogramas y comparaciones visuales entre tiendas.  

4. **Síntesis e interpretación de hallazgos**  
   - Se elaboró un informe final explicando las conclusiones y la tienda recomendada.

---

## 📊 Principales hallazgos

- La **Tienda 1** obtuvo los **mayores ingresos totales**, aunque con costos de envío más altos.  
- La **Tienda 3** se destacó por tener la **mejor calificación promedio (4.05)** y un **balance óptimo** entre ingresos, diversidad de productos y costos logísticos.  
- Las **categorías “Muebles” y “Electrónicos”** fueron las más vendidas en todas las tiendas.  
- Las **categorías con menor demanda** fueron “Artículos para el hogar” y “Libros”.  
- La **Tienda 3** presentó la mayor diversidad de artículos vendidos y un perfil equilibrado entre rentabilidad y satisfacción del cliente.

---

## 🏁 Conclusión

Tras comparar todos los indicadores, se recomienda que el **Sr. Juan comercialice sus productos en la Tienda 3**, ya que combina:

- Alta calificación de clientes.  
- Diversificación de productos vendidos.  
- Costos de envío competitivos.  
- Ingresos totales estables.  

Esto convierte a la Tienda 3 en la **opción más sólida, rentable y sostenible** para la expansión de su negocio.
